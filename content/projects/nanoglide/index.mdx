## Overview

{/*
  - wearable gyroscope module: hand orientation → directional commands
  - MPU6050 accel/gyro reads yaw/pitch/roll
  - Arduino Nano translates orientation into F/B/R/L/S commands
  - sent over Bluetooth (HC-05) to a receiver
  - intended applications: assistive tech (wheelchair direction), home
    automation (door access), robotics / interactive systems
*/}
